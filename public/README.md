# Public assets

Drop static files here — they're served from the site root (`/`).

## Founder photo (required)

Save Vijesh Reddy's headshot as:

```
public/founder.jpg
```

The Team section automatically uses it. A square crop (e.g. 800×800) looks best.
Until the file exists, the site shows a styled placeholder — no broken image.

You can also use `.png` — if you do, change the `photo` path in
`components/sections/Team.tsx` from `/founder.jpg` to `/founder.png`.

## Optional

- `og-image.png` (1200×630) — social share preview image.
- `favicon.ico` — browser tab icon.
