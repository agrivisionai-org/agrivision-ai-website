# AGRIVISION AI

Building the Future of Agriculture with Artificial Intelligence.

A premium, production-ready Next.js website for AGRIVISION AI — the AI-first AgriTech company behind the flagship **YieldAI Global** platform.

## Stack

Next.js 14 · React 18 · TypeScript · Tailwind CSS · Framer Motion · Lucide Icons.

## Sections

1. Hero — global command center, live stats, live world map
2. About AGRIVISION AI — focus areas + company timeline
3. Products — YieldAI Global, CropVision, AgriSense, FarmOS
4. Building AgriTech Products — capabilities + lifecycle
5. Low-pesticide agriculture — sustainability impact
6. Services — 8-card services grid
7. Analytics dashboard — 8 widgets
8. Pricing — Starter / Pro / Enterprise (Global + India)
9. Team — founder
10. Careers — tracks + apply
11. Contact — paths + form

## Develop

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
npm start            # serve production build
```

## Production integrations (wired as placeholders)

- **FastAPI** backend — `/api` integration points to add as needed.
- **PostgreSQL** — primary store.
- **OpenAI** — LLMs for advisory + voice assistant.
- **Stripe** — billing for Starter / Pro / Enterprise (currently a Stripe Checkout link is the next step).
- **Cloudflare R2** — object storage.
- **Vercel** — hosting target (zero-config deploy).
- **Google Maps + OpenWeather** — map + weather signals.
- **PostHog** — product analytics.
- **Clerk** — authentication.

Production website · SEO meta · responsive · 60fps animations · accessible color contrast · enterprise visual identity.
